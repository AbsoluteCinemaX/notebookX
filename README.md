# notebookX
An all-in-one workspace for notes, documents, and collaboration

notebookX — платформа для совместной работы с заметками, документами и информацией, вдохновлённая Notion.
Проект разрабатывается командой из трёх человек с использованием Go, PostgreSQL и современных веб-технологий. Основная цель — создать удобное рабочее пространство для хранения информации, организации заметок и совместной работы.
О проекте
notebookX позволит пользователям создавать рабочие пространства, управлять страницами и документами, организовывать информацию и взаимодействовать с другими участниками.
Планируемые возможности
• Регистрация и аутентификация пользователей
• Создание и управление рабочими пространствами (Workspaces)
• Создание, редактирование и удаление страниц
• Редактор заметок и документов с форматированием текста
• Вложенные страницы и иерархическая организация контента
• Управление доступом и правами пользователей
• Загрузка файлов и изображений
• Совместное редактирование документов в реальном времени
• Поиск и организация информации
Технологический стек
Backend
• Go (Golang) — разработка серверной части
• Gin — HTTP-фреймворк
• PostgreSQL — реляционная база данных
• sqlc + pgx — типобезопасная работа с базой данных
• golang-migrate — управление миграциями базы данных
• WebSocket — обмен данными в реальном времени
Frontend
• React — разработка пользовательского интерфейса
• TypeScript — типизация JavaScript
• Next.js — frontend-фреймворк
• Tailwind CSS — стилизация интерфейса
• Tiptap — редактор форматированного текста
Infrastructure & Tools
• Docker & Docker Compose — контейнеризация и локальное окружение
• Git & GitHub — контроль версий и командная разработка
• GitHub Actions — автоматизация CI/CD
• Swagger / OpenAPI — документация API
• MinIO — объектное хранилище для файлов
• Redis — кеширование и обмен сообщениями при необходимости
Технологический стек и список возможностей могут изменяться в процессе разработки.
Команда и распределение обязанностей
Проект разрабатывается командой из трёх человек.
1. Абзал — Backend Developer
Основное направление: проектирование базы данных и работа с данными
• Проектирование структуры базы данных PostgreSQL
• Создание таблиц, связей, ограничений и индексов
• Разработка и поддержка миграций базы данных
• Написание SQL-запросов с использованием sqlc и pgx
• Проектирование моделей данных для пользователей, рабочих пространств, страниц и документов
• Обеспечение целостности данных и оптимизация запросов
• Интеграция слоя работы с базой данных с backend-логикой
• Совместная работа с backend-разработчиком над архитектурой хранения данных
2. Альмансур — Backend Developer
Основное направление: REST API и бизнес-логика
• Разработка REST API на Go с использованием Gin
• Реализация регистрации, аутентификации и авторизации
• Разработка логики управления рабочими пространствами и страницами
• Реализация системы прав доступа к документам
• Интеграция API с базой данных PostgreSQL
• Обработка ошибок и валидация входящих данных
• Документирование API с помощью Swagger / OpenAPI
• Участие в проектировании backend-архитектуры
3. Исмаил — Frontend Developer
Основное направление: пользовательский интерфейс
• Разработка интерфейса на React и TypeScript
• Создание структуры рабочего пространства, боковой панели и навигации
• Реализация редактора заметок с помощью Tiptap
• Интеграция frontend с backend API
• Создание переиспользуемых UI-компонентов
• Разработка адаптивного интерфейса
• Обработка состояний загрузки, ошибок и валидации форм
• Улучшение удобства использования и визуального оформления приложения
Архитектура проекта
На начальном этапе используется модульный монолит.
• Frontend — отображает интерфейс и взаимодействует с backend через HTTP API.
• Backend — отвечает за бизнес-логику, аутентификацию, авторизацию и обработку данных.
• PostgreSQL — хранит пользователей, рабочие пространства, страницы и связанные данные.
• MinIO — предназначен для хранения загружаемых файлов и изображений.
• WebSocket — будет использоваться для функций совместного редактирования в реальном времени.
